## Problem

A milestone ships when it is tagged and installable, not when the last PR merges.

## Proposal

Move the `[Unreleased]` changelog entries under `[0.1.0]`, bump `pyproject.toml`, merge
that through a PR, then tag `v0.1.0` on `main`. The release workflow publishes the notes.

## Acceptance criteria

- [ ] `uv tool install git+https://github.com/oddurs/fairest-coin@v0.1.0` installs a working `coin`
- [ ] The GitHub release exists with generated notes
- [ ] `coin --version` prints `coin 0.1.0`
